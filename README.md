# Alpha Frontend Design

Isolierter Arbeitsbereich für das 6-Bot-UI-Team von CRAFTFLOW.

Zweck:
- UI- und Frontend-Arbeit getrennt vom produktiven Haupt-Repository
- keine Secrets, produktiven Zugangsdaten oder internen Source-Dateien
- Änderungen nur innerhalb dieses Repositories
- Übernahme in produktive Repositories ausschließlich nach menschlicher Prüfung und Freigabe

Verbindliche Arbeitsregeln stehen in AGENTS.md.
